# NeoRead Gin 个人版

基于 [cynicalight/NeoRead](https://github.com/cynicalight/NeoRead) 的 **v0.10.0**，保留原项目结构、第三方来源与许可文件。个人版本号：**0.10.1-gin.6**。

## 本版调整

- 普通单击原文或译文保持当前位置和缩放；保留选字、批注与现有工具栏。
- 原文保持 PDF 整页排版，减少正文悬停分块框线。
- 减少悬停重绘、段落扫描和几何重复读取，双栏同步直接跟随当前阅读侧。阅读位置变化时复用未变化的译文段落和公式校验，新增译文只刷新对应段落。
- 分栏边缘使用局部鼠标样式；滚动条状态只在滚动开始、结束时变化，避免整页样式反复重算。
- 放大 PDF 滚动时复用现有画布，停下约 0.1 秒后补齐高清局部；不可见译文跳过排版与绘制，滚动同步只测量附近页面。
- 默认按原文正文主体字号匹配译文；手动设置的译文字号比例继续生效。
- 顶部四角框按钮按当前页正文、双栏文字、图表的整体范围适配，减少原 PDF 页边距造成的空白。原文件保持完整。
- 新增无干扰“逐段对照”单栏阅读模式（PDF 与 EPUB 通用）：顶部切换“仅原文 / 原文译文 / 逐段对照 / 仅译文”，单栏按一段原文、一段译文交替展示，去除悬浮框与悬浮按钮，支持单栏“适配页面与文字”、原文多子图组合原样保留与点击放大，以及原文/译文双向划词批注。
- 新增文末图表“角落小窗悬浮对照”与经济学 `(Author, Year)` 文献引用定位：点击正文或译文中的图表编号（如 `Figure 2`、`Table 1`、`Figure A.9`、`表 A.27`）或作者年份引用（如 `Hayek 1978`、`North et al. 1990`、`Sun和Abraham（2021）`），在右下角弹出可移动、缩放、调大小的非模态悬浮小窗对照查看，也可一键跳转原页。
- 强化 Working Paper 等预印本的作者、年份与出处识别：自动从无 DOI/arXiv 工作论文（LaTeX 初稿、NBER、SSRN、CEPR、IZA 等）首页版面、作者单位脚注与 PDF 元信息中精准提取多位作者署名顺序、最新修订年份与 `Working Paper` 出处。
- 导出译文 PDF 支持“纯中文译文”与“逐段原文+译文”两种单栏版式，并完整保留图表、矢量公式、双向批注与目录书签；阅读界面顶栏提供快捷“导出”按钮，论文库与图书库右键菜单同步提供纯译文与逐段对照导出入口。
- 个人版使用独立版本标记，更新通过本私密仓库维护，避免替换为上游安装包后丢失这些修改。

## 本地构建

运行环境与构建方式见原项目 README：Node.js 22+、pnpm 10.30.3、Go 1.26.5+。

```text
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
node scripts/release-source.mjs
pnpm package
```

Windows 与 macOS 安装包生成到 `release/`。保持原 `appId`（`io.github.cynicalight.neoread`）与应用名称（`NeoRead`），使同一套安装包同时支持**全新安装**与**保留数据的覆盖更新**：

- **之前安装过的用户（更新）**：无需卸载旧版，退出当前运行的 NeoRead 后，macOS 打开 `.dmg` 将 `NeoRead.app` 拖入 `Applications` 选择“替换”，Windows 直接运行 `.exe` 覆盖原安装目录；原有书库、文献、译文缓存、批注笔记、AI 对话、API 与代理设置全部自动保留。
- **从未安装过的用户（新装）**：macOS 拖入 `Applications`（首次打开如遇安全拦截，在“系统设置 → 隐私与安全性”点击“仍要打开”），Windows 运行 `.exe` 按向导安装（SmartScreen 选择“更多信息 → 仍要运行”），首次启动自动初始化书库与新手引导。
