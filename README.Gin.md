# NeoRead Gin 个人版

基于 [cynicalight/NeoRead](https://github.com/cynicalight/NeoRead) 的 **v0.10.0**，保留原项目结构、第三方来源与许可文件。个人版本号：**0.10.1-gin.3**。

## 本版调整

- 普通单击原文或译文保持当前位置和缩放；保留选字、批注与现有工具栏。
- 原文保持 PDF 整页排版，减少正文悬停分块框线。
- 减少悬停重绘、段落扫描和几何重复读取，双栏同步直接跟随当前阅读侧。阅读位置变化时复用未变化的译文段落和公式校验，新增译文只刷新对应段落。
- 分栏边缘使用局部鼠标样式；滚动条状态只在滚动开始、结束时变化，避免整页样式反复重算。
- 放大 PDF 滚动时复用现有画布，停下约 0.1 秒后补齐高清局部；不可见译文跳过排版与绘制，滚动同步只测量附近页面。
- 默认按原文正文主体字号匹配译文；手动设置的译文字号比例继续生效。
- 顶部四角框按钮按当前页正文、双栏文字、图表的整体范围适配，减少原 PDF 页边距造成的空白。原文件保持完整。
- 个人版使用独立版本标记，更新通过本私密仓库维护，避免替换为上游安装包后丢失这些修改。

## 本地构建

运行环境与构建方式见原项目 README：Node.js 22+、pnpm 10.30.3、Go 1.26.5+。

```text
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
node scripts/release-source.mjs
pnpm package
```

Windows 安装包生成到 `release/`。保持原 appId 与应用名称，使更新能沿用现有书库和设置。替换安装前应关闭 NeoRead 并备份应用、用户设置和书库。

## 验证记录

阅读相关回归测试、类型检查与完整构建通过。Windows 全量测试存在上游路径假设、符号链接权限、外部工具与超时相关失败；部分失败已在未修改的 v0.10.0 源码复现，未扩大本次改动范围去修复。原项目持续集成在 Linux 上执行全量检查。

源码仓库仅保存代码与构建说明。书库、原始文档、批注、对话、运行日志、账户凭据与本地备份不进入 Git。
